2. `extension HeelerTerminalView: UIDropInteractionDelegate` removed; bodies moved to a new `HeelerTerminalDropDelegate` (fileprivate helpers `canStageDrop`, `acceptsStagingDrop`, `performStagingDrop` on the view). Upstream's `UITerminalView+Drop.swift` conforms with non-open members and auto-installs its own UIDropInteraction in `setupDropInput()`, so `installMediaDrop()` now removes any existing UIDropInteraction before adding Kelpie's.

Kelpie's other recognisers keep `self` and now inherit upstream's implementation (returns true only for its hover recogniser — same outcome as the old code for them).
