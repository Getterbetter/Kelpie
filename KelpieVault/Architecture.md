# Architecture

Inherited from [[Heeler upstream|Heeler]] except where marked **Kelpie**. Paths are relative to `~/Developer/Kelpie`.

## The stack

- **SwiftUI**, Swift 6 strict concurrency, iOS/iPadOS 18+. Project generated by **XcodeGen** from `project.yml` into the committed `Heeler.xcodeproj`.
- **Terminal emulation and rendering: libghostty**, through the `GhosttyTerminal` SPM package — Metal rendering, its own scrollback, its own `UITerminalView` UIKit surface and hardware-key encoder. **Kelpie** vendors that package under `Packages/GhosttyTerminal` (pinned libghostty-spm commit `356f730b`) because of the download quirk in [[Build and deploy]]. Never edited; extended only by overriding `open` members.
- **SSH: libssh2 + OpenSSL**, through the repo-local `Packages/HeelerSSH` package with checked-in, checksum-verified xcframeworks. Auth by password or on-device Ed25519 key; keys and passwords live in the Keychain (`ThisDeviceOnly`, no iCloud sync), Host records in `UserDefaults` with no secrets.
- **Two paths to [[herdr]] over the one SSH connection:**
  1. **Socket API** — `direct-streamlocal` channels onto `~/.config/herdr/herdr.sock` (or `sessions/<name>/herdr.sock`), carrying herdr's NDJSON JSON-RPC. One long-lived channel carries the event stream. `Sources/Heeler/Transport/`.
  2. **PTY exec** — an SSH PTY channel running a herdr client command as the remote command, raw bytes both ways. `herdr agent attach` and `herdr terminal attach` are single-pane attaches; **Kelpie** added bare `herdr` (the full client).

## Root navigation after round 2

`Sources/Heeler/ContentView.swift` roots **`HerdrClientRootView`** (`Sources/Heeler/Client/`) instead of `ConsoleView`.

```
ContentView                       ← owns every long-lived store and .task
└── HerdrClientRootView
    ├── no Hosts  → ConsoleView   ← its real "No Hosts" onboarding, unchanged
    └── a Host    → HerdrClientHostView(.id(host.id))
                    ├── HerdrClientView        ← full-screen herdr TUI
                    ├── notification banner overlay
                    └── ellipsis.circle menu   → Agents (fullScreenCover: ConsoleView)
                                                 Hosts (sheet: HostListView)
                                                 Switch Host (submenu, >1 Host)
                                                 Settings (sheet)
                                                 Reconnect
```

- The **primary Host** is a `Host.ID` persisted in `UserDefaults` under `kelpie.primary-host`, defaulting to the first Host and healing when that Host is deleted (`PrimaryHostStore`).
- **The Console is demoted, not removed.** `ConsoleStore`, `HostLiveActivityCoordinator`, `NotificationPreferencesStore`, `PushRegistrationStore` and the `ConsoleActivityDriver` `.task` all still live on `ContentView`'s body, above the cover — so push and Live Activities are unaffected by whether the cover is up.
- **Notification deep links** present the cover by themselves when `notificationRouter.path` becomes non-empty; dismissing it clears the path.
- **One Transport serves one Attach channel.** The client calls `leave()` and the cover is presented only once that channel has actually closed; it rejoins on dismissal and on `.onAppear`, and leaves on `.onDisappear` so a Host switch does not strand a channel.
- Round 1's `columnVisibility` logic in `ConsoleView` is untouched — it now applies inside the cover.

## The client attach

`HeelerSSHTransport.attachExecCommand` builds one `sh -c` line for every attach target:

```
/bin/sh -c '<PATH export>; export COLORTERM=truecolor; export LANG="${LANG:-en_US.UTF-8}";
            export HERDR_SOCKET_PATH="$2"; printf "<handshake marker>"; exec herdr [--session "$1"]'
           attach '<target>' '<socket>'
```

- `TerminalAttachTarget.client(session:)` is **Kelpie**'s addition; it never passes `--takeover`. The session name rides as a single-quoted positional argument expanded from `"$1"`, so shell metacharacters are inert; `'`, `\` and control characters are rejected outright.
- The command word stays a bare `herdr`, so exit 127 still classifies as `herdrBinaryNotFound`. `HerdrHostPath.pathExport` prefixes `$PATH` with well-known install prefixes.
- `AttachBootstrapHandshake`'s marker is printed last before `exec`, so `AttachBootstrapGate` can hide pre-exec shell chatter.
- Initial and resized `cols`/`rows` come from Ghostty's viewport callback, through `onSizeChanged` into the attach store, out as a libssh2 PTY-size request.

## How input flows

Everything below happens in `HeelerTerminalView`, a subclass of Ghostty's `UITerminalView`. `TerminalModeTracker` parses DECSET sequences out of the remote's output, so `tracksMouse` means "herdr (or another TUI) has asked for mouse reports" — it is the switch between *we own this gesture* and *hand it to Ghostty*.

### Touch (direct)

| Gesture | Behaviour |
| --- | --- |
| Tap | If the cell holds a URL → open it and stop. Else, while `tracksMouse`, a left press+release report; otherwise raise the keyboard. |
| One-finger pan | `scrollTouch(translationY:)` — local libghostty scrollback, or SGR wheel reports on the alternate screen. |
| One-finger long press (0.5 s) | **Kelpie** — while `tracksMouse`, `remoteRightClickSequence` (button 2, press then release) at that cell, with a medium haptic; the release is suppressed so it cannot arrive as a stray left click herdr would read as choosing a menu row. While `!tracksMouse`, Ghostty's own selection long press is left alone. |
| Two-finger long press | **Kelpie** — while `tracksMouse`, the text-selection sheet, fed from `readViewportText()`. |
| Pinch | Font zoom, persisted. |

### Pointer (trackpad and mouse, `.indirectPointer`)

Ghostty's UIKit layer normally owns indirect pointers and synthesises mouse events itself. Kelpie intervenes in `touchesBegan`/`Moved`/`Ended`/`Cancelled`:

- **Right button, while `tracksMouse`:** claim the whole sequence, forward nothing to `super`, report press and release from the release location. Necessary because Ghostty arms its iPadOS copy menu on `.began` from a stale drag-selection rect before `selectionMenuPoint(at:)` is ever consulted. The `selectionMenuPoint` and `contextMenuInteraction` overrides (both returning nil while `tracksMouse`) remain as a second line of defence.
- **Primary button beginning on a URL:** claim the sequence the same way; open on release only if the ended cell resolves to the same URL. Past 8 pt of movement the claim is released — `super.touchesBegan` is replayed and every later phase forwarded — so a selection drag that starts on a link still works.
- **Scroll:** a scroll-type `UIPanGestureRecognizer` (`allowedScrollTypesMask` continuous + discrete, `allowedTouchTypes` `.indirectPointer`) feeds the same `scrollTouch(translationY:)` the finger pan uses, with the same sign convention. Events carrying a touch are ignored — those are Ghostty's own pointer drag-selection. Ghostty only installs such a pan under macCatalyst, so without this a two-finger trackpad swipe did nothing on iPadOS.

### Hardware keyboard

Ghostty owns it, and that is correct: every key travels through `ghostty_surface_key`, so DECCKM cursor sequences, the kitty keyboard protocol and modifier-aware escapes all stay right. Ctrl+letter chords are claimed with `UIKeyCommand`s carrying `wantsPriorityOverSystemBehavior` so UIKit's emacs bindings cannot swallow them — which is why **Ctrl+B, herdr's prefix, reaches the PTY**. Heeler's own `pressesBegan` override intercepts only ⌘+ / ⌘= / ⌘- / ⌘_ for font zoom and forwards everything else. Cmd+C/Cmd+V fall through to the responder chain.

## Link interception

herdr hit-tests a clicked cell against OSC 8 hyperlinks and then plain-text URL patterns, and opens the winner with `open` **on the Mac**. Kelpie must therefore answer the tap itself and never send the click.

`TerminalLinkDetector` is pure and unit-tested. Given the viewport rows and a 1-based (column, row) it:

1. scans by hand for `https?://[^\s<>"'` + backtick + `]+` (by hand, not by regex, so character offsets line up with grid columns), leftmost-first and non-overlapping;
2. joins the next row's leading non-space run **only when the match reaches the grid's last column** — a viewport read drops trailing padding, so gating on "the row's string ended" would have joined an unrelated word onto every line that happens to end in a URL;
3. strips trailing `.,;:!?)]}'"` after the join;
4. passes the result through `TerminalLinkPolicy.url(for:)`, which allows only `http`/`https`. `ftp:`, `file:` and `javascript:` never match the scheme scan at all.

`HeelerTerminalView.linkURL(at:)` maps the point to a cell, reads `session.readViewportText()`, and hands the result to `onOpenLink` — wired to SwiftUI's `openURL`, which is the iPadOS default browser. No in-app browser.

## Automatic keyboard mode

`HardwareKeyboardObserver` (`@Observable`, `@MainActor`) seeds `isConnected` from `GCKeyboard.coalesced != nil` and updates on `GCKeyboardDidConnect` / `GCKeyboardDidDisconnect`, re-reading `coalesced` on a disconnect so a second attached keyboard still counts. GameController is the only honest signal: UIKit reports the *software* keyboard's frame, which is zero whether a hardware keyboard is attached or nothing has focus.

- **Client screen:** keyboard attached → no control pad, terminal takes first responder on appear. No keyboard → `TerminalControlPadView` above the software keyboard, exactly as the shell terminal does. Live on connect and disconnect.
- **Agents console:** `AgentInputModePreference` gains `.automatic` and takes it as the default (same `agent-input-mode` key), resolving to Direct Input with a keyboard and the Composer without. An explicit Composer or Keyboard choice still wins and still persists; Settings offers all three.
